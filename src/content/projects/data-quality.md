## The problem

How can recurring checks detect data inconsistencies before they affect downstream analysis?

## Approach to document

Define explicit rules for schema, missing values, uniqueness and cross-field consistency. Produce actionable reports rather than a single pass/fail flag.

## Evidence to add

- A reproducible example using public or synthetic data.
- A baseline and a clearly defined evaluation procedure.
- Results, error analysis and limitations.
- A public repository with setup instructions.

This page defines the intended case-study structure. It does not claim benchmark results or provide a completed implementation.
